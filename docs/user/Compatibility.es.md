# Lista de compatibilidad

Esta página se construye a partir de los [informes de compatibilidad](CompatibilityReports.es.md) de
los jugadores cada vez que se publica la web de la guía: consúltala en
[javocsoft.github.io/Kaichii/es/Compatibility](https://javocsoft.github.io/Kaichii/es/Compatibility/),
o mira los informes directamente con la
[etiqueta compatibility](https://github.com/javocsoft/Kaichii/issues?q=label%3Acompatibility).
