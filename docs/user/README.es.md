# Guía de Kaichii

Kaichii es un emulador de Nintendo Switch y Switch 2 para los ordenadores que la gente tiene de
verdad: portátiles y tarjetas gráficas con 4 GB de memoria de vídeo incluidos. Esta guía te lleva de
la descarga a jugar, y te ayuda cuando algo falla.

> [!NOTE]
> Kaichii no está afiliado a Nintendo. No incluye juegos, claves ni firmware: usa solo juegos y
> archivos del sistema obtenidos legalmente de tu propia consola.
